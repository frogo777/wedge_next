# Ruta desde cero

| Fase | Resultado esperado | Criterio de salida |
|---|---|---|
| 1. Fundación | Repositorio independiente y alcance | Historia propia y decisiones documentadas |
| 2. Experiencia | Prototipo nuevo con datos sintéticos | Recorrido principal usable y comprobado |
| 3. Acceso | Cuentas, sesiones y permisos | Aislamiento entre usuarios y recuperación probados |
| 4. Privacidad y operación | Procedimientos, avisos y responsabilidades | Documentación y práctica revisadas antes de datos reales |
| 5. Documentos | Ingesta y organización fiscal | Archivos válidos trazables y manejo de errores |
| 6. Cálculo | Motor fiscal versionado | Casos de referencia y revisión profesional |
| 7. Cierre | Aprobación, presentación y evidencia de pago | Primer cierre real verificable |
| 8. Piloto | Cohorte pequeña atendida | Uso, errores, tiempos y costos medidos |
| 9. Venta | Contratación, cobro y cancelación | Flujo comercial probado y promesas sustentadas |
| 10. Escala | Adquisición repetible y mayor capacidad | Retención y contribución sostenidas |

Estas fases corresponden al nuevo repositorio. Los avances de software anteriores no cuentan como implementación de este proyecto.

Al cerrar cada fase, reportar evidencia, métricas de Wedge, autoevaluación de ejecución y comparación relevante con competidores. Usar «no evaluado» cuando no haya pruebas suficientes. No inventar puntuaciones de seguridad o rendimiento.
