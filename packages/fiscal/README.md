# Motor fiscal

Directorio reservado para reglas fiscales determinísticas y versionadas. Aún no contiene cálculos.

Cada regla deberá identificar fuente oficial, vigencia, entradas, resultados y supuestos. Sus casos de referencia deberán cubrir límites y errores relevantes. El motor no enviará declaraciones ni decidirá por sí mismo que un pago está confirmado.
