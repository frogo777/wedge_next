# Aplicación web

La fase 2 se implementa como un prototipo estático nuevo en `dist/`, en la raíz del repositorio, para validar el recorrido sin infraestructura de cuentas ni dependencias pesadas.

Este directorio se mantiene para la evolución posterior. Al introducir autenticación, persistencia e integraciones, se elegirá y documentará la arquitectura de aplicación y se migrará el prototipo dentro de este mismo repositorio. No hay dos aplicaciones en paralelo.
